# ECOCLEAN SL v1.0.0 Release Candidate Notes

This release candidate delivers the database-backed Sierra Leone pilot platform for four roles: Citizen, Staff, Supervisor, and Administrator.

Citizens can register, authenticate, manage profiles, create geotagged waste reports, capture or select photographic evidence, receive notifications, and communicate through support conversations. Supervisors and Administrators can review jurisdiction-scoped reports, assign or reassign work, review evidence, verify completion, communicate with users, and export professional operational documents. Staff can see their assigned workload, update field progress, and submit mandatory completion evidence.

Validated locally: TypeScript, production build, live database connectivity, authentication for all four roles, RBAC, uploads, assignment persistence, notification creation, and all six export formats.

External certification gates remain: production Google Maps key and billing authorization, real email/SMS/push credentials, ClamAV deployment, authoritative Sierra Leone boundary polygons, Windows/XAMPP execution, and independent penetration testing.
