# ECOCLEAN SL 1.0.0 Release Candidate Notes

This is a release candidate, not a certified 1.0.0 production release. It includes self-owned JWT/RBAC authentication, five role portals, normalized MariaDB workflows, reports/tasks/support/notifications, secure uploads, GIS foundations, audit logs, backups, monitoring endpoints and all-role profiles.

Release blockers: real notification providers, ClamAV certification, authoritative GIS import, Windows XAMPP execution, independent penetration testing and production service supervision. The package version remains pre-release until these gates close.
