# ECOCLEAN SL Code of Conduct

Authorized contributors must communicate professionally, respect Sierra Leone's communities and institutions, protect personal and operational data, and avoid discrimination, harassment, intimidation, or misuse of privileged access.

Project decisions must prioritize public safety, data integrity, accessibility, security, and the documented product scope. Suspected misconduct should be reported privately to the project owner. The owner may remove access, reject contributions, or take further action when this code or the proprietary license is violated.
