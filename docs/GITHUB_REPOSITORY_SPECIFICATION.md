# GitHub Repository Specification

Recommended repository name: **ecoclean-sl-platform**

Recommended description: **Proprietary smart waste management and environmental intelligence platform for Sierra Leone.**

Create it as a **private** repository under an ECOCLEAN SL organization or owner account. Do not initialize it with a README, licence or `.gitignore` because the project already contains these files. Default branch: `main`. Development branch: `develop`. Protect `main`; require pull requests, passing tests/build, resolved conversations and restricted force pushes.

Suggested topics: `sierra-leone`, `waste-management`, `environmental-intelligence`, `gis`, `react`, `typescript`, `express`, `mariadb`, `xampp`, `government-tech`.

The first tag should be `v1.0.0-rc.1`, not `v1.0.0`, until the production-certification blockers are closed.
