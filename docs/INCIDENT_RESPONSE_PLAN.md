# Incident Response Plan

Severity 1 covers confirmed data disclosure, authentication compromise, destructive malware or complete national outage. Severity 2 covers municipal outage, failed backups, notification outage or suspected unauthorized access. Severity 3 covers isolated errors with a workaround.

Operators must identify, contain, preserve evidence, eradicate, restore, notify authorized leadership and document lessons learned. Revoke affected sessions/API keys, rotate secrets, quarantine uploads and preserve immutable audit/security logs. Restore only from checksum-verified backups. A named incident commander, security lead, database owner, communications owner and municipal contact must be assigned before pilot launch.
